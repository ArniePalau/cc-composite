# Legacy image assets

The images in this directory were supplied by the Cavallers del Cel site owner
from their existing local Forumify/MILHQ installation. They are bundled only so
that `cc-composite:import-legacy` can reproduce that installation.

The software license in the repository does not grant additional rights to
third-party artwork. Replace or remove these files if you do not have permission
to use them on your own Forumify installation.
